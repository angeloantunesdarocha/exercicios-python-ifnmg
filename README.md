# Exercícios Python - IFNMG

## 📚 Sobre
Este repositório reúne exercícios desenvolvidos durante meus estudos de Python no curso de Bacharelado em Sistemas de Informação do Instituto Federal do Norte de Minas Gerais (IFNMG).

O objetivo é praticar lógica de programação, resolução de problemas e os fundamentos da linguagem Python.

## 🗂️ Estrutura do projeto

```text
01-entrada-saida/
  numero_mensagem.py
  saudacao_usuario.py

02-operadores/
  calculadora_imc.py
  quatro_operacoes.py

03-calculos/
  lucro_festa.py
```

## 🚀 Como executar
1. Instale o Python 3.
2. Clone o repositório:
```bash
git clone https://github.com/angeloantunesdarocha/exercicios-python-ifnmg.git
```
3. Entre na pasta do projeto:
```bash
cd exercicios-python-ifnmg
```
4. Execute o exercício desejado:
```bash
python 01-entrada-saida/numero_mensagem.py
```
