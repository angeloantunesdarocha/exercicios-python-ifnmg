# Exercícios Python - IFNMG

## Sobre o Projeto

Este repositório reúne exercícios e atividades práticas desenvolvidos durante meus estudos de Python no curso de Bacharelado em Sistemas de Informação do IFNMG (Instituto Federal do Norte de Minas Gerais).

O objetivo do projeto é fortalecer os fundamentos de programação por meio da resolução de problemas, implementação de algoritmos e desenvolvimento da lógica computacional utilizando Python.

## Conteúdo

Os exercícios abordam temas fundamentais para a formação em programação, incluindo:

- Cálculo de salário líquido
- Valor da hora de trabalho
- Cálculo de IMC
- Média de notas
- Operações matemáticas
- Interação com usuário
- Resolução de problemas utilizando lógica de programação

## Tecnologias Utilizadas

- Python

## Competências Desenvolvidas

- Lógica de programação
- Estruturas básicas da linguagem Python
- Manipulação de variáveis e operadores
- Entrada e saída de dados
- Resolução de problemas
- Organização de código

## Contexto Acadêmico

Projeto desenvolvido como parte das atividades acadêmicas do curso de Bacharelado em Sistemas de Informação, contribuindo para a construção de uma base sólida em programação e para o desenvolvimento contínuo de habilidades técnicas na área de tecnologia.
